# Move Zeroes

## Problem
Given an array of integers, move all zeroes to the end of the array while maintaining the relative order of the non-zero elements.

## Link
https://leetcode.com/problems/move-zeroes/

## Approach
I first moved all non-zero elements to the front of the array. After that, I filled the remaining positions with zeroes.

## Complexity
- Time: O(n)
- Space: O(1)

## Notes
The solution modifies the array in place and keeps the non-zero elements in their original order.
